# Tutor Algebraico — Vite + React refactor

This branch adds a Vite + React scaffold and a modularized source tree.

How to run locally:

1. npm install
2. npm run dev

Notes:
- The demo uses KaTeX for rendering and mathjs for algebraic equivalence checks.
- For production, remove any client-side "teacher" secrets and add server-side authentication and CSP headers.
